## 資料間・仕様案との差

手引書のチュートリアルにはEC2のMQTT端末、IoT Core、S3保存、REST APIの例があります。グループ課題のEC2不使用とは適用範囲が異なるため、本システムにはチュートリアルの構成をそのまま採用しません。元仕様のスマホ → API Gateway → Lambda → DynamoDBを維持します。

IoT Core・MQTT・LINE通知は本システムの必須機能としては追加しません。HTTP APIとREST APIのどちらを採用するか、DynamoDB StreamsやCloudFrontを授業環境の権限で構成できるかは未確定です。

2025年度概要資料の週数・時限・10分発表・約4ページのレポート・アカウント削除時期は、2026年度にも適用されるか教員・TAの案内で確認します。概要資料内でも発表時限はp.22とp.26で表記が異なるため、具体的な日程は確定扱いにしません。

2026年版手引書中にもPython 3.8・3.9のサンプルがあります。ランタイムやライブラリのバージョンは例から固定せず、実装時に利用可能なものを確認して決めます。
