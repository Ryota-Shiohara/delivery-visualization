# 0002：D担当のローカルダッシュボード

状態：ローカル確認用に採用。2026年10月12日。

## 選択と理由

HTML・CSS・JavaScriptとLeaflet 1.9.4でD画面を作る。Node.jsの標準HTTP機能でローカル参照APIを動かす。npm依存のインストール・ビルドなしで、このPC上ですぐ表示・連携確認を行える構成にした。AのReact/Viteアプリとは独立した担当単位として保存する。

Cの10月11日共有案をそのまま使い、解析1件・配送集計・GPS区画集計を別入力とする。共有例の100件の集計と1件の解析結果はそのまま保持し、表示件数との差を知らせる。操作デモは360件の架空データで、出所を常に画面に表示する。

振動単位、cellId規則、evalStatus、スコア範囲、GPS品質基準、DynamoDBのキーは未確定。地図は区画中心を描き、良路・悪路の判定をDで新設しない。背景地図なしを標準とし、OpenStreetMapタイルの利用は利用者がオンにした場合のみ。

## AWS接続への移行

今回のNodeサーバーはローカル専用。AWS参照LambdaとS3配信用パッケージは別に実装し、DynamoDBの共有例による仮表示を確認した。最終統合用のキー・検索・ページングはB・Cと合意する。画面の配信はS3のHTTPSオブジェクトURLを採用済み。CloudFrontを要件に戻さない。

GitHubへのpush、AWSデプロイ、worktree作成は行わない。
